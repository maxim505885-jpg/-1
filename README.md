# СПУ — инженерия

Одностраничный сайт ООО «Строительно-производственное управление» в обновлённом визуальном направлении.

## Просмотр

Откройте `index.html` в браузере. Сайт собран на обычных HTML, CSS и JavaScript, установка зависимостей не требуется.

## Структура

- `index.html` — содержание и структура страницы;
- `styles.css` — адаптивная сетка, оформление и иллюстрации;
- `script.js` — мобильная навигация, появление блоков при прокрутке и прокрутка проектов.

Контактная кнопка открывает новое письмо на `info@spu-pr.ru`. Данные формы никуда автоматически не отправляются.
