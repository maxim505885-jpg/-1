# СПУ — инженерная среда

Иммерсивная одностраничная презентация ООО «Строительно-производственное управление»: шесть сюжетных сцен и 100 плавных кадров анимации модели, рассчитанных по 13 основным позам и связанным с прокруткой. Архитектурный CGI СПУ сочетается с процедурным полем частиц, чёрной сценой, свободной типографикой и фиолетовыми и янтарными акцентами.

## Просмотр

Откройте `index.html` в браузере. Установка зависимостей и сборка не требуются.

## Файлы

- `index.html` — контент и структура шести сцен;
- `styles.css` — визуальное оформление, адаптивность, переходы и прокручиваемая 3D-композиция;
- `script.js` — расчёт 100 кадров по основным ключевым позам, смена сцен, курсорный параллакс и анимированное поле частиц;
- `assets/spu-arctic.png` и `assets/spu-core.png` — CGI-иллюстрации для сцены и центральной модели.

Контактные ссылки открывают письмо или звонок. Ссылки на объекты ведут на официальный сайт СПУ.
